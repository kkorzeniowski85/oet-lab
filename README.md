# OET Lab

Aplikacja do przygotowania do egzaminu OET (Medicine): zwroty, sposoby pisania i mówienia oraz ćwiczenia,
podzielone na sekcje jak egzamin. Działa w przeglądarce telefonu i komputera, także bez internetu.
Dane zostają na urządzeniu.

## Praca nad kodem

```bash
npm install
npm run dev      # podgląd na http://localhost:5173
npm test         # testy
npm run lint     # sprawdzenie kodu
npm run build    # wersja produkcyjna w dist/
```

Wymaga Node 22.12 lub nowszego.
